How do I try it on one device?

On the events screen, tap Add Demo Event. It creates a small contest with competitors, judges and categories, so you can score, approve and watch the standings without setting anything up.

My devices can't find each other

  • Every device must have ScoreDeck open, with Wi-Fi and Bluetooth turned on (no router or internet is needed).
  • Allow Local Network access when iOS asks. If you said no, turn it on in the Settings app › ScoreDeck.
  • Each device picks a role: one Master, any number of Judges and Screens.

Do I need an account or an API key?

No. Scoring, syncing and standings work with no account and no key. Generating an event banner or rider avatar with AI is optional and uses your own OpenAI key, added in Settings. Without a key you can still add photos from your library.

Can I move an event to another device?

Yes. Long-press an event and choose Export Event, then open the file on the other device or use Import Event from the + menu.
