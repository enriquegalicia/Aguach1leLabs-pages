Do I need a key or a Google Sheet?

No. Events, contacts, lead scores, card scanning and follow-up drafts all work on your iPhone with nothing set up. A Google Sheet adds sync with a spreadsheet you own; an OpenAI key adds an optional cloud reader for cards and an extra drafting voice.

How do I connect a Google Sheet?

In Ventureo, open Settings → Set up your Sheet. It's easiest on a computer:

  1. Create a Google Sheet with two tabs, Events and Contacts. The app copies each tab's header row for you.
  2. In the Sheet, open Extensions → Apps Script and paste in the Ventureo script. Tap Send script to your computer in the app to email or AirDrop it to yourself.
  3. Choose setup in the function menu and press Run. Google asks you to authorize it, because it's your own script in your own account. The log shows your sync token.
  4. Deploy → New deployment → Web app, with Execute as: Me and Who has access: Anyone. Copy the Web app URL (it ends in /exec).
  5. Back in Ventureo, paste the URL and the token in Settings under the Sheet section, tap Save sync settings, then pull down on the Contacts or Events tab to sync.

Why does the script need access set to "Anyone"?

That's what lets your phone reach it. Every request must also carry your sync token, and the script refuses anything without it, so the URL on its own is useless to anyone else. Keep the token private, like a password.

"The sync token was rejected"

The token in Settings doesn't match the one your script generated. Run setup again in Apps Script (it keeps the same token) and copy it from the log.

I set up my Sheet before October 2026 and rows come back blank

An early version of the script wrote blank IDs. Paste the current script from Set up your Sheet, run setup once more, then use Deploy → Manage deployments → Edit → New version so the same URL serves the new code.

The card scan missed a field

Cards are read on your iPhone. Try a flat, well-lit shot that fills the frame, then fix anything by hand. If you added an OpenAI key and allowed sending contact data to OpenAI in Settings, the cloud reader is used instead and usually reads tricky cards better.
