¿Necesito una clave o una Hoja de Google?

No. Eventos, contactos, calificaciones, escaneo de tarjetas y borradores de seguimiento funcionan en tu iPhone sin configurar nada. Una Hoja de Google agrega sincronización con una hoja de cálculo tuya; una clave de OpenAI agrega un lector opcional de tarjetas en la nube y otra voz para redactar.

¿Cómo conecto una Hoja de Google?

En Ventureo, abre Ajustes → Configura tu Hoja. Es más fácil en una computadora:

  1. Crea una Hoja de Google con dos pestañas, Events y Contacts. Los nombres van tal cual, en inglés. La app copia por ti la fila de encabezados de cada pestaña.
  2. En la Hoja, abre Extensiones → Apps Script y pega el script de Ventureo. Toca Enviar el script a tu computadora en la app para mandártelo por correo o AirDrop.
  3. Elige setup en el menú de funciones y presiona Ejecutar (Run). Google te pide autorizarlo, porque es tu propio script en tu propia cuenta. El registro muestra tu token de sincronización.
  4. Implementar → Nueva implementación → Aplicación web (Deploy → New deployment → Web app), con Ejecutar como: Yo (Me) y Quién tiene acceso: Cualquier usuario (Anyone). Copia la URL de la aplicación web (termina en /exec).
  5. De vuelta en Ventureo, pega la URL y el token en Ajustes, en la sección de la Hoja, toca Guardar ajustes de sincronización y luego desliza hacia abajo en la pestaña Contactos o Eventos para sincronizar.

¿Por qué el script necesita acceso de "Cualquier usuario"?

Eso es lo que permite que tu teléfono llegue a él. Cada solicitud también debe llevar tu token de sincronización, y el script rechaza lo que no lo traiga, así que la URL por sí sola no le sirve a nadie más. Guarda el token en privado, como una contraseña.

"Se rechazó el token de sincronización"

El token en Ajustes no coincide con el que generó tu script. Vuelve a ejecutar setup en Apps Script (conserva el mismo token) y cópialo del registro.

Configuré mi Hoja antes de octubre de 2026 y las filas regresan en blanco

Una versión anterior del script escribía IDs en blanco. Pega el script actual desde Configura tu Hoja, vuelve a ejecutar setup y luego usa Implementar → Administrar implementaciones → Editar → Nueva versión (Deploy → Manage deployments → Edit → New version) para que la misma URL sirva el código nuevo.

El escaneo de la tarjeta se saltó un campo

Las tarjetas se leen en tu iPhone. Prueba una toma plana y bien iluminada que llene el cuadro, y corrige lo demás a mano. Si agregaste una clave de OpenAI y permitiste enviar datos de contacto a OpenAI en Ajustes, se usa en su lugar el lector en la nube, que suele leer mejor las tarjetas difíciles.
