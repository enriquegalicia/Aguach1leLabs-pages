PageWiser — Política de privacidad

PageWiser se está reconstruyendo como ayuda de lectura para quienes empiezan a leer. Esta página describe la versión anterior, que nunca se publicó, y se actualizará antes de que salga la nueva.

Última actualización: julio de 2026

PageWiser guarda todo localmente: tu historial de lectura y tus preferencias se guardan solo en tu dispositivo, con el framework SwiftData de Apple. Aguach1leLabs no opera ningún servidor y no hay cuenta ni inicio de sesión: nunca recibimos ni guardamos tus datos.

Cámara

PageWiser pide acceso a la cámara para que escanees una página que estás leyendo. La imagen de la página se envía directamente de tu dispositivo a la API de OpenAI, con una clave de API que tú proporcionas y controlas en Ajustes, para obtener ayuda de comprensión y explicaciones. Aguach1leLabs nunca ve, guarda ni tiene acceso a estas fotos ni a tu clave de API.

Tu propia clave de IA (BYOK)

PageWiser usa un modelo de "trae tu propia clave" para las funciones de IA en la nube. Tu clave de API de OpenAI se guarda solo en el Llavero de tu dispositivo, cifrada por iOS. Nunca se transmite a Aguach1leLabs, no se registra ni se incluye en ningún archivo al que tengamos acceso.

Lo que no hacemos

  • Sin analítica ni SDK de reportes de fallos
  • Sin publicidad ni redes de anuncios
  • Sin rastreo entre apps o sitios web de otras empresas
  • No vendemos tus datos: de entrada, no tenemos forma de recopilarlos

Terceros

El único tercero con el que PageWiser se comunica es OpenAI, y solo para la página específica que eliges escanear, con tu propia clave de API. El manejo de esa solicitud por parte de OpenAI se rige por la política de privacidad de OpenAI.

Privacidad de los menores

PageWiser no está dirigida a menores y no recopila a sabiendas información de nadie.

Cambios a esta política

Si esta política cambia, la versión actualizada se publicará en esta misma URL con una nueva fecha de "última actualización".
