How do I connect a Google Sheet?

In PostLeap, open Settings → Sync → Set up your Sheet. It walks you through the whole setup, and it's easiest on a computer:

  1. Create a Google Sheet with three tabs: Posts, Guidelines and Graphics. The app copies each tab's header row for you.
  2. In the Sheet, open Extensions → Apps Script and paste in the PostLeap script. Tap Send script to your computer in the app to email or AirDrop it to yourself.
  3. Choose setup in the function menu and press Run. Google asks you to authorize it, because it's your own script in your own account. The log shows your sync token.
  4. Deploy → New deployment → Web app, with Execute as: Me and Who has access: Anyone. Copy the Web app URL (it ends in /exec).
  5. Back in PostLeap, paste the URL and the token under Settings → Sync, tap Save, then pull down on the Calendar to sync.

Why does the script need access set to "Anyone"?

That's what lets your phone reach it. Every request must also carry your sync token, and the script refuses anything without it, so the URL on its own is useless to anyone else. Keep the token private, like a password.

"The sync token was rejected"

The token in Settings → Sync doesn't match the one your script generated. Run setup again in Apps Script (it keeps the same token) and copy it from the log.

"Couldn't read the Sheet's response" or "check that its tabs and headers match"

A tab name or header is spelled differently from the setup guide. Names must match exactly, but column order doesn't matter. If you changed the script, use Deploy → Manage deployments → Edit → New version so the same URL serves the new code.

I deleted something and it came back

Don't delete rows in the Sheet. Tick Archived instead. Swiping a post or guideline away in PostLeap does the same thing. If your Sheet was set up before September 2026, add an Archived column to the Guidelines and Graphics tabs and run setup once more.

A teammate's change isn't showing up

Pull down on the Calendar to sync. When the same post changed on both sides, the newer edit wins for the whole row. Changes made by Make or other automations must also set the UpdatedAt column, or PostLeap won't notice them.

Does AI drafting need a key?

Yes. Paste your own OpenAI key under Settings → AI. It's stored in your iPhone's Keychain and sent only to OpenAI. Without a key, everything else still works: accounts, the calendar, guidelines and sync.

Does PostLeap post to Instagram, LinkedIn or X?

No. PostLeap drafts, approves and schedules. Publishing happens from your Sheet, for example with a Make scenario that posts rows marked Approved.
